> **גישה ציבורית, פתוחה ושיתופית** למידע על מערכת העננט (Oracle Cloud ERP) של אוניברסיטת בר-אילן — מבוסס על 7 הקלטות הדרכה רשמיות, 40 מסמכי PDF הדרכתיים, ושאלות-תשובות מהבוט הציבורי של מחלקת הרכש.

🌐 **אתר ציבורי**: [ananet-knowledge.pages.dev](https://ananet-knowledge.pages.dev) (כולל חיפוש מלא + בוט שיחה)

## 📥 הורדת המאגר

### דרך 1: GitHub (קל ביותר)
```bash
git clone https://github.com/elad-refoua/ananet-knowledge.git
```

### דרך 2: ZIP
לחץ על "Code → Download ZIP" בעמוד הריפו.

### דרך 3: קובץ בודד
כל קובץ בדף שלו ב-GitHub עם כפתור "Download raw file". באתר הציבורי — כל מידע מקושר ישירות לקובץ המקורי.
