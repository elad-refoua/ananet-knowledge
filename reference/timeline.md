## 📜 ההיסטוריה הקצרה

**עננט** = פלטפורמת Oracle Fusion Cloud ERP החליפה את **ברנט** (פיתוח פנימי של בר-אילן).

### למה ההחלפה?
- ברנט היה מערכת ישנה (פיתוח פנימי במשך 20 שנה)
- בעיות תחזוקה, אבטחה, אינטגרציה
- Oracle Cloud מציע: SSO M365, ממשק מודרני, ענן (לא דורש שרתים פנימיים), מודולים מתקדמים

### למה לקח 6 שנים?
- COVID 2020-2022 עיכב הכל
- Oracle Cloud דורש התאמות נרחבות לעבודה ישראלית (מע"מ, חשבונות בנק ישראליים, חוקי רכש ציבורי)
- מיגרציה של נתונים היסטוריים מברנט (~20 שנה של רכש)

### מה שונה?
| נושא | ברנט | עננט |
|---|---|---|
| התחברות | שם משתמש + סיסמה ייעודיים | M365 SSO |
| מודלים | מקומי (אודיטוריום) | ענן |
| ממשק | desktop-first | web responsive |
| הרשאות | לפי תפקיד נטען | לפי dynamic role |
| חוקר עורך דרישה | לא — קניין יערך | **כן — רק החוקר** |
| חיפוש | תפריטים | wildcard `%X%` |
| validation | מיידי במסך | ברקע עד 10 דקות |
| הזמנות = דרישות | דחוס לאחד | מופרדים (דרישה 2*, הזמנה 4*) |

ראה [`glossary-brnet-vs-ananet.md`](glossary-brnet-vs-ananet.md) למיפוי מלא של מונחים.
