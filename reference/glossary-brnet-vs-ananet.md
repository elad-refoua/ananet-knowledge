# מילון: ברנט → עננט

מיפוי מונחים מהמערכת הישנה (ברנט) למערכת החדשה (עננט). זה מקל על ההסתגלות אם אתה כבר מכיר את ברנט.

---

## 🔑 מונחים מרכזיים

| ברנט | עננט | הערות |
|---|---|---|
| התחברות עם שם משתמש + סיסמה ייעודיים | **SSO** דרך M365 | אותם credentials של אאוטלוק / חשבון בר-אילן |
| מערכת desktop | **ממשק web** | בכל דפדפן, בכל מכשיר |
| תפריטים מקובעים | **חיפוש wildcard `%X%`** | יותר גמיש |
| הקניין מתקן את הדרישה | **רק הדורש מתקן** | שינוי משמעותי! |
| validation מיידי במסך | **Test Validation ברקע (~10 דק')** | שונה מהותית |
| מספר אחד לדרישה+הזמנה | **דרישה (2*) ≠ הזמנה (4*)** | הופרדו |
| מחסן מרכזי | **מחסן כללי** | אותו דבר, שם חדש |
| ועדת תשומות | **ועדת תשומות (Inputs Committee)** | אותה ועדה |
| העדפות אישיות | **עדכן העדפות דרישת רכש** | תפריט חדש |
| הצגה | **PDF download** | אותה פונקציה |
| חשבון תקציבי | **חשבון חיוב** | אותו דבר |
| תפריט "המידע שלי" | **טאב Me** | תפריט עליון |
| ביטול דרישה | **הסר** (Remove) | ניסוח חדש |

---

## 🛒 מסכי דרישות

| ברנט | עננט |
|---|---|
| מסך הזמנות (גוש אחד) | **רכש → דרישות רכש** + **רכש → ניהול דרישות** (מופרדים) |
| הקלדת שורות בדרישה | **משימות נוספות → הזנת שורת דרישת רכש** |
| בחירת ספק חופשית | **חיפוש ספק במאגר** (אם לא במאגר → "GENERAL") |
| צירוף קבצים | **נספחים** ברמת ההדר |
| העתקת דרישה | **שכפול** (פעולה במסך ניהול דרישות) |

---

## 🏷️ ערכי תכונה (חדש לחלוטין)

זה שדה שלא היה בברנט בצורה הזאת. הוא **קריטי** לניתוב הדרישה לקניין הנכון:

| ערך תכונה | מתי משתמשים |
|---|---|
| **אחר** | רכש מקומי / מלאי / כללי |
| **ייבוא** | דרישת יבוא (פותח שדות ספציפיים) |
| **ייצוא** | דרישת יצוא |
| **הסעים** | אוטובוסים / מוניות (פותח מסלול / שעות / כביש 6) |
| **חומרים מסוכנים** | חומ"ס (פותח מק"ט מעבדה / קוד / SDS) |

## 📦 מלאי ומחסן

| ברנט | עננט |
|---|---|
| המחסן המרכזי | **מחסן כללי** |
| הזמנה מהמחסן (צריכה אישור) | **רכש מהמלאי** (אישור פנימי, לא קניין) |
| **סוג מקור** | חדש: יש לבחור `מלאי` (לא `ספק חיצוני`) |
| **סוג יעד** | חדש: יש לבחור `הוצאה` |
| תשומה אוטומטי | ❌ אסור — אף פריט מהמחסן אינו תשומה |

## 🌍 רכש חו"ל

| ברנט | עננט |
|---|---|
| תיאור בעברית, הקניין מתרגם | **תיאור באנגלית בלבד** (עובר ישירות לספק) |
| הקניין מקליד שורות העמסה | **הדורש מקליד** (אחרי שהקניין מחשב) |
| כל הפרטים בדרישה אחת | **שורה נפרדת לכל פריט** |
| מטבע "GENERAL" | מטבע ספציפי (USD/EUR/וכו') |
| הצעה אחת = מספיק | **3 הצעות מ-60K**; **ועדת תשומות מ-100K** |

## 🧪 חומ"ס

| ברנט | עננט |
|---|---|
| מק"ט אחד פר חומר | **מק"ט פר גודל אריזה** (50g vs 100g = שונים) |
| חיפוש לפי שם בלבד | חיפוש לפי **תיאור / מכיל / CAS** |
| קוד מעבדה כללי | **קוד מעבדה אישי** (מקבלים ע"י ספירת מלאי) |
| לא היה SDS V check | **חובה לסמן V** על קריאת SDS |
| דיווח שימוש בנייר | **מסך דיווח למעבדה** (דיגיטלי) |
| אישור BIRD נפרד | **רכישה מבירד** (ספק רגיל בעננט) |

## 🆔 מספרי הזמנה / דרישה

מערכת המספור השתנתה ב-עננט:

| מספר מתחיל ב- | משמעות |
|---|---|
| **1** | הזמנה שמועברה מברנט (היסטורית) |
| **2** (7 ספרות) | דרישת רכש בעננט (לפני אישור) |
| **4** (7 ספרות) | הזמנת רכש בעננט (אחרי אישור) |
| מספר קצר | הזמנה פנימית (מחסן) |

**קל לזהות:** אם רואה מספר → מתחיל ב-1 → ברנט; ב-2 → דרישה חדשה; ב-4 → הזמנה חדשה.

## 🔁 מה לא השתנה?

- **רוב הקטגוריות** (101-994) — אותן הקטגוריות
- **קודי CAS** של חומ"ס — אותם
- **שמות קניינים** — רוב האנשים נשארו (אבל יש שינויים בתחומים)
- **מבנה תקציב** של בר-אילן (סעיפים, חשבונות) — אותו דבר
- **ספי הצעות מחיר** (20K/60K/100K) — אותם
- **ועדת תשומות** — אותה ועדה
- **כתובות אימייל ליצירת קשר** — אותם

---

**טיפ למעבר**: אם אתה מכיר את ברנט — רוב הידע שלך עדיין רלוונטי. ההבדלים העיקריים הם בממשק (web vs desktop), הניווט (חיפוש wildcard), ובמה שאתה אחראי לעצמך (עורך את הדרישה במקום הקניין).
